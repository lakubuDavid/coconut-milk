# Add ctx:call_on_main() for background→main explicit forwarding

## Description
Explicit forwarding method on CoconutContext for bg commands:

- ctx:call_on_main(commandName, args) → returns a Future
- Available only on bg thread (is_main_thread == false); throws on main thread
- Generates callId via bg->next_call_id.fetch_add(1)
- Pushes ForwardRequest{callId, commandName, argsJson} to bg->outbox
- dispatch::notify(app) to wake main thread
- Creates Future(callId, bg), stores in bg->pending_futures
- Returns Future to Lua

Used by the implicit proxy and by explicit command author calls:
  local result = ctx:call_on_main("dialog.open", { title = "Open" }):await()

The stub implementations for dialog.*, notify.*, clipboard.*, store.*
can use call_on_main internally instead of duplicating the forwarding logic.
