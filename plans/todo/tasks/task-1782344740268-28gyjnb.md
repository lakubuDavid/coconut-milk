# Replace bg-side error stubs with forwarding stubs

## Description
Currently bg-side stubs for dialog.open, dialog.save, dialog.message, notify, clipboard, store return error messages. Replace them with forwarding stubs that:
1. Generate a callId (UUID or counter)
2. Push ForwardRequest{callId, "dialog.open", args} to bg->outbox
3. dispatch::notify(app) to wake main thread
4. Create Future(callId, bg) and store in bg->pending_futures
5. Return Future to Lua caller
Same pattern for: dialog.open, dialog.save, dialog.message, notify.send, clipboard.readText, clipboard.writeText, store.get, store.set, openUrl
