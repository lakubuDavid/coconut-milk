# Add std::condition_variable wake-up for bg thread

## Description
Replace the polling sleep_for(5ms) with a condition_variable-based wake-up:

- Add std::mutex + std::condition_variable to bg_thread::Context
- Replace sleep_for in run loop with wait_for(5ms, predicate checking inbox non-empty)
- Main thread calls bg->cv.notify_one() after pushing to bg->inbox:
  - From dispatch::drain (after pushing ForwardResult)
  - From bridge::dispatchRpcCallToLua (after pushing CommandCall)
  - From ctx:call_on_bg() (after pushing BgCommandCall)
- Does NOT change any lock-free properties of the outbox — cv is purely a wake-up optimization
- Predicate prevents spurious wakeups:
  auto checkInbox = [&]{ return !bg->inbox.empty() || !bg->running.load(); };
