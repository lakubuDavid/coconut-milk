# Implement implicit forwarding via metatable proxy (bg thread)

## Description
Instead of manually registering stubs for each main-thread-only API on the bg thread, use Lua metatables to auto-intercept any access to unknown coconut.* members.

Approach:
1. Set a __index metamethod on the bg thread's global table (or the coconut table itself)
2. When code accesses coconut.dialog, coconut.notify, coconut.clipboard, coconut.store, coconut.openUrl etc. and the key doesn't exist, the metamethod fires
3. The metamethod returns a proxy table with its own __index metamethod
4. Any method call on the proxy (e.g., proxy.open(args)) generates a ForwardRequest and returns a Future
5. Alternatively, the __index could return a callable that does the forwarding

This eliminates the need to pre-declare which APIs are main-thread-only — any missing coconut.* access auto-forwards. Reduces boilerplate and keeps bg→main forwarding zero-maintenance.

RISK: Masks real nil-access bugs. Mitigation: Only apply to coconut.* subkeys, not to _G. Log forwarded calls at debug level.
