# Event object refactor — unify event dispatch with DOM-like event model

## Description
Refactor event dispatch to use a single event object (table) instead of (name, payload, ctx). DOM semantics: preventDefault/stopPropagation. Name stays separate in RPC envelope (#1). Three consumer tiers become: coconut.on(event, cb), coconut.on_EVENT_NAME(event), coconut.events(event). Affects bridge C++, Lua runtime, JS consumers, examples, tests, docs.
