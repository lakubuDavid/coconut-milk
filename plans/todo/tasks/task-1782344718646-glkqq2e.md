# Add ForwardRequest/ForwardResult/ForwardError/BgCommandCall/EmitEvent message kinds

## Description
Five new dispatch::MessageKind values:
- ForwardRequest: Bg→Main, payload = "callId|commandName|jsonArgs" (via bg->outbox)
- ForwardResult: Main→Bg, payload = "callId|jsonResult" (via bg->inbox)
- ForwardError: Main→Bg, payload = "callId|jsonError" (via bg->inbox)
- BgCommandCall: Main→Bg, payload = "callId|commandName|jsonArgs" (via bg->inbox, for ctx:call_on_bg())
- EmitEvent: Bg→Main, payload = "eventName|jsonPayload" (via bg->outbox, for ctx:emit() from bg thread)
All use same pipe-separated payload format. The kind discriminates direction and routing table.
