# Event propagation model: stopPropagation vs preventDefault semantics

## Description
DOM semantics: stopPropagation() stops event from reaching next tiers. preventDefault() sets defaultPrevented flag for cancellable events (close, etc.) — does not affect propagation. stopImmediatePropagation() for within-tier. Three-tier chain: view:on → coconut.on → coconut.events.
