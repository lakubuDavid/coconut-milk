# Opt-in: compile config to bytecode on bundle (B2)

## Description
When bundle.bytecode_config is true: compile the stripped coconut.config.lua to .luac via luajit -b <arch> before bundling. Runtime loader handles .luac transparently. User must bundle separately per arch if using this opt-in.
