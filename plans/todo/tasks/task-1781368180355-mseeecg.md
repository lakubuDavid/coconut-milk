# Strip dev-only fields from config on bundle (Option A default)

## Description
When bundling, coconut.config.lua gets dev fields removed: generators.*, debug.*, manifests.*, bundle.*. The stripped config ships in .app/Contents/Resources/coconut.config.lua. Runtime loads it when running from .app. Bundle-aware binary (option B) points to Resources/.
