# coconut.store — shared KV store (C++ map, string-only, event-driven sync)

## Description
- C++ unordered_map<string,string> owned by bridge::State
- Lua: coconut.store:set(k,v)/:get(k)/:has(k)/:delete(k)/:clear()/:keys() — sync C++ calls
- JS: coconut.store.set(k,v)/.get(k)/.has(k)/.delete(k)/.clear()/.keys() — async via bridge commands
- Events: set() broadcasts 'store:update' to the other side with {key, value}
- Both sides can coconut.on('store:update', cb) to react to changes
- New module: src/store.h / src/store.cpp
