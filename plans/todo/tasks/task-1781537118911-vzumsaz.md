# coconut.args — global read-only CLI args on both Lua and JS sides

## Description
- argparse::Args gets positional, named, flags fields
- Convert args to nlohmann::json after parsing, store on bridge state
- Lua: coconut.args → read-only sol::table from stored JSON
- JS: inject coconut.args during bridge init (or via __get_args command)
- { positional=["file.lua"], named={mode="dev"}, flags={verbose=true} }
- No config pollution, backward-compatible, globally accessible
