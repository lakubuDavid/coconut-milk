# Add CoconutContext::is_main_thread flag + ctx:emit() bg→main routing

## Description
CoconutContext needs thread identity so ctx:emit() can route safely:

- Add bool is_main_thread = true to CoconutContext (default main thread)
- bg_thread::create() sets bg->ctx->is_main_thread = false
- In ctx:emit():
  if (is_main_thread) {
    // Existing path: bridge::emitToJS() direct (safe, on main thread)
  } else {
    // Forward through bg->outbox via EmitEvent message kind
    std::string payload = name + "|" + jsonPayload.dump();
    app->bg->outbox.push({MessageKind::EmitEvent, payload});
    dispatch::notify(app);
  }
- dispatch::drain handles EmitEvent by calling bridge::emitToJS() on the main thread

This prevents the current unsound behavior where ctx:emit() on the bg thread
directly calls webview_eval() which is not thread-safe.
