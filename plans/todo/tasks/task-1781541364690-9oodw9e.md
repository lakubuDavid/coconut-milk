# coconut.keybind — dual-registry keybind system (JS + Lua)

## Description
- JS captures keydown → normalize combo → check JS registry
- If unconsumed → emit 'keydown' event to Lua via bridge
- Lua receives via coconut.on('keydown') → check Lua registry
- API: coconut.keybind(combo|table, fn|cmd_name, opts?) on both sides
  - combo: "mod+s" auto-maps to cmd (macOS) / ctrl (others)
  - combo: { mac="cmd+s", win="ctrl+s", linux="ctrl+s" } for explicit per-platform
  - opts.id: string identifier for override support
  - opts.scope: "global" (default) or app-defined string
- Combo format: ctrl+s, cmd+shift+p, alt+f4, esc, up, down, f1..f12
- Scope: 'global' (always active) or app-defined string
- Override API: setOverride(id, combo), clearOverride(id), loadOverrides(table), getCombo(id)
  - Overrides change effective combo at runtime, dev handles persistence
- Event payload: { key, ctrl, shift, alt, meta, scope }
- JS: keydown listener, normalization table, registry, scope management
- Lua: coconut.keybind() binding, registry table, coconut.on('keydown') handler
