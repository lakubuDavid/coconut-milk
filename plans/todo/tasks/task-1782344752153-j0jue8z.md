# Add ctx:call_on_bg() for main-thread→bg offloading

## Description
Allow main-thread commands to offload CPU-heavy work to the bg thread:
- ctx:call_on_bg("command_name", args) → returns a Future
- Pushes BgCommandCall{callId, commandName, jsonArgs} to bg->inbox
- Main thread stores Future in app->pending_main_futures[callId]
- NEVER block main thread: await() on a main-thread Future throws a Lua error ("main thread cannot block")
- Only then() callbacks work on main thread futures
- When bg finishes, pushes ForwardResult to bg->outbox
- dispatch::drain picks it up, finds matching Future in pending_main_futures, invokes then() callbacks

This is how a main-thread command calls e.g. a pure-computation command without freezing the UI.
